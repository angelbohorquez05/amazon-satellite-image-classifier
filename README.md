# Amazon Satellite Image Classifier

Finds **primary forest, water, agriculture, roads and clouds** in satellite images of the Amazon rainforest. One image can contain several at once (multi-label).

## How it works

1. Each image is described by **25 hand-crafted features**: colour (RGB, HSV), vegetation index, texture, edges and the most extreme local patches.
2. A **Random Forest with balanced class weights** predicts each label, so rare labels like water are not ignored.
3. An **Isolation Forest** flags images that look nothing like the training data, and the demo warns the user.

## Results

Trained on 40,393 images (60% train, 20% validation, 20% test). All choices were made on validation; the test set was used once.

| | Macro F1 (test) |
|---|---|
| Lazy baseline (always "primary") | 0.19 |
| **Final model** | **0.77** |

<p align="center">
  <img src="figures/fig4_model_comparison.png" alt="Macro F1 on validation of 6 models" width="700">
</p>

- Balanced class weights gave the biggest gain; PCA made results worse.
- New edge and patch features added +0.010; the anomaly score added almost nothing.
- Tuning one threshold per label did not help on test, as explained in the notebook.

Full analysis: [`notebooks/amazon_planet.ipynb`](notebooks/amazon_planet.ipynb)

## Run it

```bash
git clone https://github.com/angelbohorquez05/amazon-satellite-image-classifier.git
cd amazon-satellite-image-classifier
pip install -r requirements.txt
python demo/app.py
```

Open http://localhost:7860. The trained model is included, so no dataset is needed. To retrain, download the [Kaggle dataset](https://www.kaggle.com/c/planet-understanding-the-amazon-from-space) into `data/raw/planet/` and run the notebook.
